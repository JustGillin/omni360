# Omni360 - Store discs matched by hand
#
# make_store_titles.py ties a disc to its title ID by name, against Redump's
# datfile. These are the ones no rule there gets right. Two kinds of line:
#
#   <zip in the Redump collection, without .zip> = <title ID>
#       The datfile has no entry by that name, or a wrong serial.
#
#   <other-set item>/<file> = <title ID> <the game's Redump-style title>
#       A disc in XBOX_360_1.._6 whose name doesn't match the Redump title,
#       or that Redump has no retail entry for. It is taken as that game,
#       whatever the Redump collection holds.
#
# File names are exact, odd characters and all. Title IDs are the Xbox Live
# catalog's (src/CatalogTitles.h), checked against Redump's serial where it
# has one.
